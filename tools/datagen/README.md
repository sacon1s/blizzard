# Сбор позиций для обучения сети

`blizzard-data-linux` — программа сбора данных Blizzard под Linux: движок играет сам с собой и сам оценивает позиции.

Собирать можно на серверах GitHub, не нагружая свой компьютер: вкладка **Actions** → **Сбор позиций** → **Run workflow**. Укажите, сколько серверов запустить (до 20) и сколько часов работать (до 5,5). Когда запуск закончится, файлы с позициями появятся в разделе **Artifacts** на странице запуска.

Запуск вручную: `./blizzard-data-linux self имя-файла часов потоков`.
