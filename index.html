A chess engine with a neural network

Written from scratch.
Trained in the storm.

Blizzard is a chess engine in plain JavaScript. Its neural network learned from 11 million positions of master games, each one scored by Stockfish. It plugs into Arena, Cute Chess and En Croissant, or plays right here in your browser.

version 0.5

Blizzard has no board of its own. It runs inside a chess program, just like Stockfish: the program shows the board, and Blizzard finds the moves.

Windows 10 and 11

blizzard.exe has everything built in, so there is nothing to install.

Windows may say “Unknown publisher” on first launch, because the file has no paid code-signing certificate. Click “More info”, then “Run anyway”.

Download

macOS, Linux and others

A single blizzard-uci.js file. Needs Node.js 18 or newer: run it with node blizzard-uci.js.

Also works on Windows if you already have Node.js.

Connect it

  1. Unzip the archive

    Into any folder, for example Documents\Chess. There is no need to double-click blizzard.exe: that only opens a console window where the engine waits for commands.

  2. Add it to your chess program

  3. Adjust if you like

    Skill Level
    Strength from 1 (beginner) to 10 (full).
    Hash
    Memory for the search, in MB. 32–256 is plenty.
    MultiPV
    How many best lines to show while analysing.
    OwnBook
    Play the opening from its grandmaster book.

    Blizzard 0.5

    The engine is written from scratch in JavaScript with no third-party libraries. For matches and analysis the website runs Stockfish 19 as a separate program from the stockfish/ folder: the stockfish.js lite build, GPLv3, source code at stockfish.js and Stockfish. The two engines talk only through UCI commands; Blizzard contains no Stockfish code, and its network was trained on positions that Stockfish evaluated. Pieces: cburnett set (Colin M. L. Burnett). Opening names: lichess-org/chess-openings (CC0). Fonts: Archivo, Golos Text and Russo One, OFL.
