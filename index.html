Blizzard

A chess engine that learned from master games.

It plugs into Arena, Cute Chess, En Croissant and other chess programs. Or play it right here in your browser, at ten levels from beginner to master.

Download Blizzard 0.1

The engine has no board window of its own. It runs inside a chess program, just like Stockfish: the program shows the board, and Blizzard calculates the moves.

Windows 10 and 11

The blizzard.exe file has everything built in, so there is nothing to install.

On first launch, Windows may say “Unknown publisher” because the file has no paid code-signing certificate. Click “More info”, then “Run anyway”.

macOS, Linux and others

A single blizzard-uci.js file. Needs Node.js 18 or newer; run it with node blizzard-uci.js

Also works on Windows if you already have Node.js.

How to connect it

  1. Unzip the archive

    Into any folder, for example Documents\Chess. You don’t need to double-click blizzard.exe: that only opens a black console window where the engine waits for commands.

  2. Add the engine to your program

  3. Adjust if you like

    Skill Level
    Strength from 1 (beginner) to 10 (full).
    Hash
    Memory for the search, in MB. 32–256 is usually plenty.
    MultiPV
    How many best lines to show during analysis.
    OwnBook
    Play the opening from its own grandmaster book.

How strong it is

Blizzard played series of games against Stockfish 19 limited to a set rating.
